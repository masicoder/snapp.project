نصب و اجرا
ریپازیتوری را کلون کنید:

git clone https://github.com/masicoder/snapp.project-clone.git
cd snapp-clone

وابستگی‌های پروژه را نصب کنید:
npm install
# یا با yarn
yarn install
پروژه را اجرا کنید:
npm run dev


این پروژه صرفاً برای مقاصد آموزشی و تمرینی توسعه یافته است و هیچ وابستگی به شرکت اسنپ ندارد.

توجه: این پروژه برای اجرا نیاز به Node.js دارد.
